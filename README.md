# 《线性代数》交互式 3D 教学仿真实验平台

> 依据**深圳技术大学 · 中德智能制造学院**《线性代数》（课程编号：`SG01047`，2.5 学分 / 45 学时，面向 **2025 级机器人工程专业**）课程教学大纲设计开发。

## ✨ 平台核心特性

1. **大纲全覆盖（6 大章节下拉模块 · 31 个交互式 3D 仿真案例）**
   - 完整覆盖第 1–18 周全部教学内容（行列式、矩阵、向量、线性方程组、特征值/相似矩阵/二次型），并专门结合大纲 OBE **课程目标 3 & 4** 增设第六章**机器人工程综合应用专题**（机械臂正运动学、雅可比奇异椭球、3D 点云 PCA 姿态感知、多自由度振动模态解耦）。
2. **按章节下拉菜单式导航 + URL 直链分享**
   - 顶部提供 **[课程章节 ▾] ➔ [实验案例 ▾] 级联下拉菜单** 以及 **[📂 章节案例总菜单 ▾] 分组折叠菜单**。
   - 每个案例绑定独立 URL Hash（如 `#ch1-sarrus`、`#ch4-nonhom-struct`、`#ch6-jacobian`），教师可将具体案例链接直接放入课件 PPT 或扫码分享给学生。
3. **零外部依赖自研 WebGL + HiDPI 2D 科学三维引擎**
   - 原生硬件 Z-Buffer Phong 光照渲染 + 半透明平面深度排序 + 高分屏清晰数学标注。
   - **无需任何外部 CDN 加载**，在校园网、离线环境及 GitHub Pages 上均可毫秒级秒开，彻底杜绝外部脚本跨域或网络超时导致的白屏问题。
4. **双主题适配课堂教学**
   - 一键切换 **🌙 深空科研模式**（适合学生自主探究）与 **☀️ 课堂投影明亮模式**（适合教室大屏与投影仪授课）。

## 🚀 发布到 GitHub Pages 指南（零构建，直接托管）

本项目采用纯静态零构建架构（包含 `.nojekyll` 与自动部署工作流 `.github/workflows/deploy-pages.yml`），支持以下任意一种方式一键发布到 GitHub Pages：

### 方式一：直接从分支根目录发布（最简单）
1. 在 GitHub 新建仓库（例如 `linear-algebra-3d-lab`），将本文件夹推送至远程仓库：
   ```bash
   git init
   git add index.html .nojekyll README.md css js .github
   git commit -m "feat: 初始化《线性代数》交互式 3D 教学仿真实验平台"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/linear-algebra-3d-lab.git
   git push -u origin main
   ```
2. 打开 GitHub 仓库页面 ➔ **Settings** ➔ 左侧 **Pages**。
3. 在 **Build and deployment -> Source** 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，点击 **Save**。
4. 等待约 30 秒，即可通过 `https://<你的用户名>.github.io/linear-algebra-3d-lab/` 访问完整平台！

### 方式二：使用内置 GitHub Actions 自动发布
1. 推送代码后，进入 GitHub 仓库 **Settings** ➔ **Pages**。
2. 将 **Source** 切换为 **GitHub Actions**。
3. 仓库内置的 `.github/workflows/deploy-pages.yml` 将自动打包纯净前端静态资源并完成部署。

### 本地离线运行
- 直接双击 `index.html` 即可在 Chrome / Edge / Safari / Firefox 中流畅运行；或使用任意静态服务器预览。
